## Trust Boundaries

| Boundary | Description |
|---|---|
| Owner-supplied publication inputs → public repository | Resume, screenshots, URLs, and client facts become world-readable. |
| Markdown/frontmatter → static HTML | Structured content and prose become executable browser markup/links. |
| Portfolio → external client site | A visitor leaves the controlled static site for an external destination. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01-03 | Information Disclosure | client/resume assets | mitigate | Human publication approval; allow only screenshots/descriptions/links; never copy client source. |
| T-01-04 | Tampering / Elevation | content URLs and Markdown | mitigate | Restrict external URLs to HTTPS/mailto destinations as appropriate, use owner-controlled Markdown, and do not use arbitrary raw-HTML rendering. |
| T-01-05 | Spoofing / Availability | live client link | mitigate | Label the confirmed destination and keep the complete evidence story local so external failure does not erase it. |
| T-01-06 | Repudiation | contract claims | mitigate | Render accuracy-critical facts from structured records tied to D-05 through D-10; omit all unconfirmed claims. |
| T-01-SC | Tampering | dependency supply chain | mitigate | This plan adds no packages; retain Plan 01's lockfile and approved dependency set. |
</threat_model>
