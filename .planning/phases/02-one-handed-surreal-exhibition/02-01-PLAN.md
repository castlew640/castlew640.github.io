**Source ROADMAP `**Goal:**` line (verbatim):** "Visitors can explore a memorable surreal corridor, open the real work, and return to their place using one hand, with a complete still presentation available."

> This phase is planned under MVP mode, but the ROADMAP goal for Phase 2 is not written in

> `/gsd mvp-phase 02` if the user-story framing is wanted before execution.

<objective>

Every later plan in this phase reads this document as its specification, so it must be true before anything is built against it.

Output: pinned dependencies with a committed lockfile, a source-boundary guard wired into the deployment gate, and a corrected UI design contract.
</objective>

**Locked stack decision (developer-approved this session, supersedes UI-SPEC §Design System and §Registry Safety):**

- The scene is built on plain `three@0.186.0` plus `@types/three@0.186.0`.
- NO `react`, NO `react-dom`, NO `@react-three/fiber`, NO `@astrojs/react`.
- Measured with this repo's own esbuild: `three + Line2 + Reflector` = 151,848 B gzipped (80% of the
  UI-SPEC §I 190 KB budget). The same plus React 19.2.8 + react-dom + `@react-three/fiber@9.7.0` =

  for React to manage.
