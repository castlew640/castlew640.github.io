## Phase Goal

**Source ROADMAP `**Goal:**` line (verbatim):** "Visitors can explore a memorable surreal corridor, open the real work, and return to their place using one hand, with a complete still presentation available."

> The ROADMAP goal is not in `As a / I want to / so that` form. No user story has been invented.

**This plan's slice:** the still catalogue stops looking like a plain document and starts looking like the exhibition — a visitor with reduced motion or no WebGL sees the corridor as architectural drawings.

<objective>
Author the four inline SVG architectural drawings that carry the surreal identity in the still view, and render one at every stop.

Purpose: UI-SPEC §G.2 requires the still view to be an *illustrated* exhibition catalogue, not a bare document — real project images, static architectural drawings, and the reflection motif. D-17 makes this the presentation every failure mode converges on, so it must satisfy ART-01 on its own. The drawings also establish the ink vocabulary the WebGL scene must match in plans 02-06 and 02-07.

Output: four drawing components in the shipped ink hand, wired into the entrance, exhibit, about and landing stops.
</objective>

<decisions>
- **New drawings use `var(--token)` colours; the shipped `Fig. 01` keeps its hard-coded hex literals.**
  PATTERNS.md left this open and asks for one consistent choice. Migrating `Fig. 01` would touch a
  drawing that already passed Phase 1 visual review for no functional gain, so it stays as shipped.
- The stroke vocabulary is fixed by UI-SPEC §B.2 and is identical to the values already in `Fig. 01`:
  built structural edge `1.4px` `var(--edge)` solid; drawn-only member `1.3px` `var(--edge-unbuilt)`
  dash `5 5`; construction/datum `1px` `var(--construction)` dash `4 7`; construction arc `1px`
  `var(--construction)` dash `2 6`; registration mark `1px` `var(--registration)` solid;
  annotation leader `1.4px` `var(--rust)` solid with a 3px rust dot.
- The `35°` / `7px` pitch `construction-hatch` pattern is reused. Each drawing that needs it must
  declare its own `<pattern>` with a **document-unique id** (for example `hatch-landing`), because
  the shipped `Fig. 01` already owns the id `construction-hatch` on the same page and duplicate SVG
  ids would make the axe run and the rendering non-deterministic.
</decisions>
