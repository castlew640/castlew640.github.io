## Phase Goal

**Source ROADMAP `**Goal:**` line (verbatim):** "Visitors can explore a memorable surreal corridor, open the real work, and return to their place using one hand, with a complete still presentation available."

> The ROADMAP goal is not in `As a / I want to / so that` form. No user story has been invented.

**This plan's slice:** scrolling stops being a document scroll and becomes travel — a visitor moves through a real corridor, and every way that can fail leaves the catalogue intact.

<objective>
Stand up the WebGL2 scene: renderer, light rig, sky, camera derived from scroll, the shared ink materials, the entrance vestibule and threshold arch, demand rendering, teardown, and every failure path.

Purpose: this is the first plan where `three` enters the bundle, so it is also where the §G.1 ordering contract and the §I rendering policy become real rather than promised. UI-SPEC §G.4 requires that a renderer that cannot start, or a context that is lost, costs the visitor nothing — building those paths alongside the renderer rather than after it is what makes ACCESS-05 structural.

Output: a corridor a visitor can walk, that idles at zero cost and fails without taking navigation with it.
</objective>

three@0.186.0 facts verified from source — do not re-derive:
  - `three/addons/*` and `three/examples/jsm/*` both resolve through the package exports map.
  - `LineMaterial.linewidth` is in CSS pixel units when `worldUnits` is `false`.
  - `LineMaterial.dashSize`/`gapSize` are model-space units scaled only by `dashScale`; there is no
    screen-space term. Choose world-unit values that subtend the §B.2 pixel figures at the design
    standoff and record the conversion in a comment.
  - `Line2` requires `material.resolution` in **CSS pixels** (`renderer.getSize`, never
    `getDrawingBufferSize`), or strokes render at half weight on a DPR-2 phone.
  - `DirectionalLight.target` does nothing unless the target object is added to the scene.
  - `WebGLRenderer` is WebGL2-only since r163; a device without WebGL2 gets the HTML catalogue.

<decisions>
- **`preventDefault()` becomes legal in exactly one place.** Plans 02-04 and 02-05 asserted it
  absent from `src/scripts/`. The `webglcontextlost` handler must call it, or the context never
  becomes restorable. From this plan onward the guard narrows to: `preventDefault` appears only
  inside the `webglcontextlost` handler in `src/scripts/exhibition/scene/index.ts`, and never on a
  `wheel`, `touchstart`, `touchmove`, `pointerdown` or `pointermove` listener.
- **The canvas container is sized explicitly, not with `inset: 0`.** UI-SPEC §A.6 says
  `position: fixed; inset: 0` while §F says `100svh`; those are different boxes on iOS, where
  `inset: 0` tracks the layout viewport as the URL bar retracts. Use
  `position: fixed; top: 0; left: 0; width: 100%; height: 100svh` and debounce renderer resize so
  height changes under 8 px do not re-render. Assumption A1 — confirm on the D-18 device in 02-08.
- **The water plane is a flat `--water` surface in this plan.** The `Reflector` and the layer-2
  completed group arrive in plan 02-08; shipping a flat plane first keeps this plan's scope to the
  renderer and the mass.
- **This plan owns the automated coverage for the failure paths it builds.** The
  `getContext`-returns-`null` and `WEBGL_lose_context` cases are added to
  `tests/exhibition-resilience.spec.ts` here, in the same task that writes those paths, rather than
  in plan 02-07 two waves later. This is the phase's largest risk surface and it owns ACCESS-05;
  proving those paths with an in-page evaluation performed once during execution would leave waves 5
  and 6 with no regression net. The file already exists (plan 02-04) and is already in the
  `test:e2e` list, so this adds cases and no gate wiring. Plan 02-07 adds the chunk-abort and
  texture-failure cases to the same file.
- **This plan reads plan 02-03's `EntranceDrawing.astro`** to match the still-view ink hand, so
  02-03 is a declared dependency even though it is a wave-2 sibling of 02-04. The wave is unchanged
  at 4.
